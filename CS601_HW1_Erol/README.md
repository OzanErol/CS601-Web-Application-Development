# CS601_HW1_LastName

## Description
This project implements an interactive web form using **HTML5**, **CSS3**, and **JavaScript** only.  
It includes form validation via JavaScript (no `required` attributes), DOM manipulation, and the use of arrow functions and higher-order functions (`map()`, `filter()`).

## Instructions
1. Open `index.html` in your browser or use VS Code with the **Live Server** extension.
2. Fill out the form fields and click "Submit."
3. Errors will be displayed inline for invalid inputs.
4. On success, the form hides and a thank-you message appears below it.

## Validation
- HTML checked via [W3C HTML Validator](https://validator.w3.org/)
- CSS checked via [W3C CSS Validator](https://jigsaw.w3.org/css-validator/)
